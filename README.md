**This library is suited for Python 3.10 in combination with the following packages:**
- Matplotlib 3.5.3
- Numpy 1.24.0
- Pandas  1.5.3

The T-parameter library is developped for the simulation of Capacitive Wireless Power (CPT) transfer systems. It contains functions to calculate the output parameters of a given system as well as an optimization function to select the optimal inductor - capacitor combination in a double sided LC compensation network.
